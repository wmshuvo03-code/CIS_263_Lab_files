# 🖥️ CIS 263 - Structured Programming Language Lab

Welcome! This repository contains all C programming source codes, daily tasks, and class test verifications for the **CIS 263 (Structured Programming Language)** lab course. This repository serves as official documentation and proof for the final lab examination.

---

## 📂 Repository Structure

The repository is structured into two main directories to cleanly separate regular lab practices from official evaluations:

*   **`📂 Lab/`** - Daily lab session codes, practical exercises, and problem-solving files.
    *   `Day01.c` - Basic introduction to C programming syntax.
    *   `Day02.c` - Data types, standard input/output handling, and operators.
    *   `day03.c` - Conditional statements (if-else) and decision-making logic.
*   **`📂 Exam_Documentation/`** - Recorded class tests, quizzes, and academic proofs preserved for final evaluation.
    *   `Class_test01/` - Problems and solutions from the first official class test.

## 🚀 How to Run Locally

To clone and run these C programs on your local machine, follow these steps:

1. Clone this repository:
```bash
git clone https://github.com/wmshuvo03-code/CIS_263_Lab_files.git
```

2. Navigate to the lab directory:
```bash
cd CIS_263_Lab_files/Lab
```

3. Compile and run any specific C file (e.g., `day03.c`):
```bash
gcc day03.c -o day03
./day03
```
